# Sprint 2.3 — 作为可达性提示的局域网发现

[English version](sprint-2.3.md)

## 目标

让可信局域网配置更容易，但不把未经认证的广播变成访问权限。

## 范围

- 可选 UDP/IPv4 广播和接收循环。
- 带版本、大小限制的发现数据包，包含设备元数据和能力。
- 临时 discovered 对端接口。
- 明确区分 discovered 和 paired 对端。

## 非目标

- mDNS、自动配对、对端认证或出站同步。
- 持久化发现结果。
- 保证在屏蔽广播的网络中发现成功。

## 验收标准

- 默认关闭发现，并可配置端口和间隔。
- 非法、过大、版本错误以及自身广播会被忽略。
- 合法广播会出现在 discovered 列表中，但不会进入 paired 列表。
- 发现数据包不包含 bearer 或 peer Token。
- Stop 能取消监听器和广播协程，不能泄露资源。
- 发现不可用时仍可手动配对。

## 验证

```text
go test ./...
go vet ./...
go build ./cmd/localbridge
git diff --check
```
