# Sprint 4.1 — 文件分享与断点传输基础

[English](sprint-4.1-file-transfer.md)

状态：已下发给 `程序开发` 子任务，尚未验收。

## 目标

不再假设 iPhone 可以直接粘贴任意文件，改为安全的 URL/二维码多文件传输流程。本 Sprint
交付后端契约和最小移动端页面边界，不声称已交付 Windows 原生外壳、托盘或资源管理器菜单。

## 范围

- Windows 主机选择一个或多个文件后创建持久化分享批次。
- 不透明的公开分享 token、过期、撤销和有界文件元数据。
- 创建、查看、列表和撤销分享的 JSON API。
- 列出文件并提供下载链接的公开移动端 HTML 页面。
- 支持正确 `206`/`Content-Range` 行为和校验和元数据的 HTTP Range 下载。
- 使用顺序 `Content-Range` 分片、已提交偏移查询和续传的上传会话 API。
- 原子完成、完整文件 SHA-256 校验、安全接收目录和接受历史记录。
- 测试多文件分组、非法路径、过期/撤销、Range、中断上传、重复分片、校验和错误和重启恢复。
- 同步更新中英文协议、配置、部署和 Sprint 文档。

## 不包含

- Windows 原生 GUI、托盘图标、开机注册或资源管理器 Shell 扩展。
- 通知声音或操作系统通知集成。
- URL 推送、图片剪贴板和通用插件 API。
- 默认静默接受上传。

## 验收标准

1. 测试从多个文件创建一次分享，并得到一条可展开的分享记录；公开响应不能包含不受限制的源路径。
2. 公开 URL 可以列出并下载每个文件；Range 续传返回精确字节。
3. 上传在任意分片后中断，重启后查询偏移并继续，最终生成经过校验且不破坏已有目标文件的结果。
4. 过期或撤销 token 无法读取、上传或修改传输状态。
5. 路径穿越、符号链接逃逸、超大请求体、非法 Range 和校验和不匹配必须被拒绝。
6. `go test ./...`、`go vet ./...`、`go build ./cmd/localbridge` 和 `git diff --check` 全部通过。
