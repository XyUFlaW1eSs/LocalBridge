# Sprint 4.2 — 桌面 GUI、移动端体验与分享管理

[English](sprint-4.2-desktop-gui.md)

状态：进行中。Sprint 4.2A 与 Sprint 4.2B Windows 外壳基础已经交付；原生宿主窗口的关闭最小化语义和接收确认状态机仍待完成。

## 目标

把文件传输契约变成 Windows 上易理解的用户流程，同时让 iPhone 继续使用同一套移动端页面。
UI 采用 Web-first，但不能复制传输状态，也不能绕过后端安全边界。

## 桌面 UI 契约

应用包含三个顶层区域：

1. **文件分享**：二维码/URL 结果、文件选择/拖放区域和当前分享表格。一次多选是一条可展开的分享记录；
   子文件展示大小、校验和、进度、状态以及移除/重试操作。逐条清除和一键清除必须明确，并在必要时确认破坏性删除。
2. **接受记录**：接收链接、进行中的上传和已完成文件，展示状态、续传/重试、校验和结果、目标路径和隐私删除。
3. **设置**：开机自启、关闭最小化到托盘、资源管理器右键菜单、恢复默认、自动接受、通知声音和收发声音选择。

## 桌面外壳决策

首个 GUI 是由 LocalBridge 提供的静态 Web 前端，因此可以在浏览器测试并复用到 iPhone 页面。Windows 发布外壳在前端
契约稳定后采用基于 WebView2 的 Go 包装器（默认候选为 Wails）。外壳负责窗口生命周期、托盘菜单、单实例、开机注册
和资源管理器右键菜单安装；后端仍可独立以 CLI/无头模式运行。

## 验收标准

- 干净 Windows 启动后打开 GUI，可以创建/撤销多文件分享。
- 文件选择器的 `multiple` 和拖放都能添加文件，浏览器 UI 不泄露源路径。
- 分享记录可展开/收起，逐条清除/一键清除在重启后仍反映持久化状态。
- 二维码和复制 URL 操作生成准确的移动端公开 URL。
- 接受记录展示中断、续传、完成、失败和删除状态。
- 设置原子保存、经过校验、诊断脱敏，并实际影响运行行为。
- 关闭外壳遵循关闭最小化配置；托盘退出会停止进程。
- iPhone 可以打开同一分享/接收页面，并使用浏览器原生保存/分享行为。

## 交付拆分

- Sprint 4.2A 已交付内嵌浏览器 GUI、本地二维码、多文件分享、接收记录、设置持久化以及浏览器安全的上传/下载流程。
- Sprint 4.2B 基础已交付当前用户级开机启动和 Explorer 注册表效果、原生托盘控制、完成通知及 Explorer 多文件分享命令。
- 4.2 剩余工作是可真正执行关闭最小化的原生宿主窗口，以及在关闭自动接收时使用的明确批准/拒绝流程。
