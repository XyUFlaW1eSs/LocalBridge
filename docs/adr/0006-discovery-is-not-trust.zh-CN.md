# ADR 0006：局域网发现不是信任

[English version](0006-discovery-is-not-trust.md)

## 状态

Phase 2 Sprint 2.3 已接受。

## 决策

使用可选的有大小限制 UDP/IPv4 广播完成局域网发现。数据包包含协议版本、设备 ID/名称、API 端口、能力和 nonce。
接收端从 UDP 来源地址得到对端地址，并只把结果放入临时的 discovered 列表。

发现到的对端不会进入已配对注册表，不会获得凭据或 API 访问权。显式配对仍然是授权步骤；当广播被阻断时仍支持手动
输入地址。

## 理由

发现可以改善配置和诊断，但它未经认证且容易伪造。把发现当授权会让任意局域网参与者伪装成可信设备。临时保存发现
结果也可以避免过期或恶意广播污染持久状态。

## 影响

- 默认关闭发现；不允许广播的网络可以关闭它。
- 协议必须容忍未知能力和非法数据包。
- 未来可以使用 mDNS 或认证响应，但必须保持信任边界。
