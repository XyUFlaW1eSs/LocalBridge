# ADR 0010：版本化与脱敏的生效配置

[English version](0010-versioned-effective-configuration.md)

## 状态

Phase 2 Sprint 2.7 已接受。

## 背景

LocalBridge 过去会把默认值叠加到无版本 YAML/JSON 文档上。这样能维持简单兼容，但没有定义迁移或未来版本行为；
运维人员也无法在不直接打开可能包含密钥的配置文件时，安全查看应用默认值后的生效配置。

## 决策

- 当前根配置 Schema 为版本 1，仓库内配置明确声明 `version: 1`。
- 不含 `version` 或显式版本 0 的文档视为旧版 v0，只在内存迁移到 v1；LocalBridge 不会自动改写用户文件。
- 负版本和未来版本会被拒绝。YAML 根键/section 与 JSON 字段继续严格校验；未知值导致启动失败，而不是静默忽略。
- `GET /api/v1/system/config` 返回生效配置，时长使用人类可读格式，凭据值只显示“是否已配置”的布尔状态。
- 响应包含生效版本、来源版本、是否迁移和来源类型（`file`、`defaults` 或 `programmatic`），不暴露配置文件路径。
- 关闭认证时，本机回环可读取诊断，局域网远程请求被拒绝；启用认证后，所有请求必须使用管理 Bearer Token，普通 peer Token
  明确无权读取。

## 影响

升级现在拥有明确兼容边界，旧配置仍能启动。未来 Schema 变化必须先增加经过审查的迁移，再提升当前版本。内置 YAML
子集仍有意保持狭窄，不是通用 YAML 实现。诊断会向授权管理方显示非敏感路径和限制，因此绝不能改成公开接口。
