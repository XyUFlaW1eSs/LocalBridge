# 编码风格

[English version](coding-style.md)

- 对所有 Go 文件运行 `gofmt`。
- 保持包名简短，并聚焦单一职责。
- 使用包含操作上下文的包装错误返回值。
- 让长期运行的操作传递 `context.Context`。
- 保持 HTTP Handler 薄，将领域规则放在模块中。
- 在边界处校验输入并限制请求体大小。
- 公共负载优先使用明确的结构体，不要使用 `map[string]any`。
- 不记录剪贴板内容；剪贴板数据属于用户数据。
- 使用构建标签隔离操作系统代码，并保持平台接口足够小。
- 为公共行为和失败路径添加测试，不测试无意义的实现细节。
