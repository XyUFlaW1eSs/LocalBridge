# Roadmap

[简体中文](ROADMAP.zh-CN.md)

## Delivered

- Phase 0: repository bootstrap and core runtime.
- Phase 1 / Sprint 1: text clipboard exchange between Windows and iPhone Shortcuts.

## Phase 2 — Device and discovery

- Pairing and an authentication token.
- Device registry and LAN discovery (mDNS or UDP broadcast).
- Explicit allow-listing and connection diagnostics.

## Phase 3 — Rich clipboard

- Images and HTML clipboard formats.
- Clipboard history with bounded local storage.
- Conflict policy and per-device synchronization preferences.

## Phase 4 — LAN collaboration platform

- File transfer, URL push and notifications.
- Android, macOS and Linux clients.
- Optional desktop tray/service integration.

The roadmap is directional. Public API compatibility and local-first privacy take priority
over adding features quickly.
